# MBIntエンコード仕様.md

## 1. 目的と背景

MBInt (可変長整数) エンコードは、Galuchat固有のデータ構造における「大きさは不定だが少なくとも小さい値が一般的」という特性を考慮し、最小のバイト数で整数を表現することで、ファイルサイズの削減を目的として設計されました。

MBIntは端末での解釈の家系性を保つため、MSBファーストなバイト配列を採用しています。小さい値ほど短いバイト列になるので、パレット長やデータ長などを記録する際に大きな効果を発揮します。

---

## 2. 用語定義と記号

- **MBInt**: 符号付き可変長整数 (Multi-Byte Integer)
- **MBUInt**: 符号なしの可変長整数 (Multi-Byte Unsigned Integer)
- **prefix**: エンコード値の1バイト目の値で、表現長を判別する（この値により後続バイト数が決まる）
- **MSB-first**: バイト列は最上位バイトから順に並ぶ形式（Most Significant Byte First）
- 値はすべて、バイト列としてシリアライズ/デシリアライズされる

---

## 3. MBUInt (符号なし可変長整数)

### 3.1 フォーマット概要

| バイト数 | prefix (先頭値) | 基準値 (base) | 表現範囲             |
|----------|------------------|----------------|----------------------|
| 1B       | 0〜251           | 0              | 0〜251               |
| 2B       | 255              | 252            | 252〜507             |
| 3B       | 254              | 508            | 508〜66043           |
| 4B       | 253              | 66044          | 66044〜16843259      |
| 5B       | 252              | 16843260       | 16843260〜4311810555 |

### 3.2 実例

| 値   | バイト列              |
|------|----------------------|
| 5    | [0x05]               |
| 300  | [0xFF, 0x2E]         |
| 1000 | [0xFE, 0x01, 0xF3]   |

### 3.3 ステップバイステップ実例

例：数値 1000 の場合

1. 該当範囲を決定：
   1000 は「508〜66043」なので 3バイト形式、prefix = 254
2. 基準値を引く：
   差分 = 1000 - 508 = 492
3. 差分を 2バイトのMSB順に分割：
   492 = 0x01EC → [0x01, 0xEC]
4. バイト列構成：
   [0xFE, 0x01, 0xEC]

---

## 4. MBInt (符号付き可変長整数)

### 4.1 フォーマット概要
- 1バイト目の最上位ビットを「符号ビット」として利用 (0=+ 、 1=-)
- 値は符号なしMBUIntと同様のパターンで表現（ただしprefixは124〜127を使用）

| バイト数 | prefix (7bit部) | 基準値 (base) | 表現範囲              |
|----------|------------------|----------------|-----------------------|
| 1B       | 0〜123           | 0              | 0〜123                |
| 2B       | 127              | 124            | 124〜379              |
| 3B       | 126              | 380            | 380〜65915            |
| 4B       | 125              | 65916          | 65916〜16843131       |
| 5B       | 124              | 16843132       | 16843132〜4311810427  |

### 4.2 実例

| 値   | バイト列            |
|------|--------------------|
| 5    | [0x05]             |
| -5   | [0x85]             |
| -300 | [0x7F, 0x2E]       |

### 4.3 ステップバイステップ実例

例：数値 -1000 の場合

1. 符号を確認：負数 → 符号ビット=1
2. 絶対値：1000 → MBUIntに準じて処理
3. 該当範囲を確認：1000 は 3バイト形式、prefix = 126
4. 差分 = 1000 - 380 = 620 → 0x026C → [0x02, 0x6C]
5. バイト列構成：
   [0xFE, 0x02, 0x6C] → prefix に符号ビットを立てて [0x7E, 0x02, 0x6C]

---

## 5. 実装上の注意点

- prefix 値は固定、未定義prefixはデコードエラーとする
- MSB順に定型化されたバイト配列を保つこと
- 5バイト表現の最大値を超える値は未定義動作
- 各値はバイト列全体として処理され、他形式と区別する情報は含まれないため文脈による識別が必須

---

## 6. 擬似コード集

### 6.1 MBUInt エンコード
```python
if n < 252:
    return [n]
elif n < 508:
    return [0xFF, n - 252]
elif n < 66044:
    d = n - 508
    return [0xFE, (d >> 8) & 0xFF, d & 0xFF]
elif n < 16843260:
    d = n - 66044
    return [0xFD, (d >> 16) & 0xFF, (d >> 8) & 0xFF, d & 0xFF]
else:
    d = n - 16843260
    return [0xFC, (d >> 24) & 0xFF, (d >> 16) & 0xFF, (d >> 8) & 0xFF, d & 0xFF]
```

### 6.2 MBUInt デコード
```python
head = b[0]
if head <= 251:
    return head
elif head == 0xFF:
    return 252 + b[1]
elif head == 0xFE:
    return 508 + (b[1] << 8) + b[2]
elif head == 0xFD:
    return 66044 + (b[1] << 16) + (b[2] << 8) + b[3]
elif head == 0xFC:
    return 16843260 + (b[1] << 24) + (b[2] << 16) + (b[3] << 8) + b[4]
```

### 6.3 MBInt エンコード
```python
sig = 0 if n >= 0 else 1
x = abs(n)
if x < 124:
    return [x | (sig << 7)]
elif x < 380:
    d = x - 124
    return [0x7F | (sig << 7), d]
elif x < 65916:
    d = x - 380
    return [0x7E | (sig << 7), (d >> 8) & 0xFF, d & 0xFF]
elif x < 16843132:
    d = x - 65916
    return [0x7D | (sig << 7), (d >> 16) & 0xFF, (d >> 8) & 0xFF, d & 0xFF]
else:
    d = x - 16843132
    return [0x7C | (sig << 7), (d >> 24) & 0xFF, (d >> 16) & 0xFF, (d >> 8) & 0xFF, d & 0xFF]
```

### 6.4 MBInt デコード
```python
head = b[0]
sig = (head & 0x80) >> 7
prefix = head & 0x7F
if prefix < 124:
    return (prefix) * (-1 if sig else 1)
elif prefix == 127:
    return (124 + b[1]) * (-1 if sig else 1)
elif prefix == 126:
    return (380 + (b[1] << 8) + b[2]) * (-1 if sig else 1)
elif prefix == 125:
    return (65916 + (b[1] << 16) + (b[2] << 8) + b[3]) * (-1 if sig else 1)
elif prefix == 124:
    return (16843132 + (b[1] << 24) + (b[2] << 16) + (b[3] << 8) + b[4]) * (-1 if sig else 1)
```

### 6.5 制限事項
> ⚠️ 本形式は **型情報を持ちません**。すなわち、任意のバイト列からそれが MBInt（符号付き）なのか MBUInt（符号なし）なのかを識別する手段は存在しません。呼び出し元の構造・文脈によりどちらであるかを事前に知っておく必要があります。
