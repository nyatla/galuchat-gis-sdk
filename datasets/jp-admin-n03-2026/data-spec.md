# 国土数値情報 行政区域データ N03-20260101

## 1. 概要

本データセットは、国土交通省が提供する「国土数値情報（行政区域データ）N03-20260101」を、Galuchatのオフライン逆ジオコーディング用に加工したリリースパッケージである。日本全国の行政区域を、WGSMapSet/3の区域地図とGisWordBook/0の名称辞書として提供する。

| 項目 | 内容 |
| --- | --- |
| データセット名 | 国土数値情報 行政区域データ N03-20260101 |
| リリースパッケージID | `jp-2026-mlit-go-jp-n03-adm` |
| 対象地域 | 日本全国 |
| 対象区域 | 都道府県、振興局、郡、市区町村および政令指定都市の行政区 |
| 入力座標系 | JGD2011地理座標（EPSG:6668） |
| 出力座標系 | WGS 84互換の緯度経度格子 |
| 座標変換 | なし。入力のJGD2011座標値を再投影・測地系変換せず、WGS 84互換の座標値として格納する。 |
| 原典版・基準時点 | `N03-20260101`、2026年1月1日時点 |

### 1.1 対象範囲

47都道府県の通常行政区域Shapefileを統合した、日本全国の行政区域を表す。入力ZIPに含まれる北海道の振興局別派生ファイルは採用せず、通常行政区域ファイルに含まれる都道府県、振興局、郡、市区町村および政令指定都市の行政区を対象とする。

### 1.2 水域の扱い

| 水域 | クリップ方式 | データとしての意味 |
| --- | --- | --- |
| 外水面 | `FULL` | 原典の行政区域は、国土地理院「数値地図（国土基本情報）」を基に、詳細な海岸線で外水面を除外している。追加の水域クリップは行わない。 |
| 内水面 | `NONE` | 内水面は一律には除外されず、原典の行政区域ポリゴンに含まれる湖沼・河川は区域として扱う。追加の水域クリップは行わない。 |

### 1.3 領域・境界

日本全国の47都道府県の通常行政区域Shapefileの収録範囲を対象とし、原典に含まれる島嶼・飛地その他の区域も採用する。

| 項目 | 扱い | データとしての意味・備考 |
| --- | --- | --- |
| 国境側の境界 | 該当なし | 収録対象に隣接する国・地域との陸上の国境区間はない。海岸側の扱いは第1.2節に従う。 |
| 対象領域外 | 背景値 | 採用区域面の外側。 |
| 対象領域内の未割当地点 | 背景値 | 採用面に穴・区域間の隙間がある場合の未割当地点、またはサンプリングで区域が選ばれなかった地点。 |

背景値だけでは領域外、水域、内部の未割当地点を区別できない。区域コードも陸域のみを示す値ではなく、水域の扱いは第1.2節に従う。

格子化により境界のずれや背景画素が生じ得る。区域図の境目を正確な国境線・原典のベクトル境界として使用しない。

### 1.4 ID・コード空間

| 項目 | 定義 |
| --- | --- |
| 原典ID | `N03_007`が表す全国地方公共団体コード。 |
| 原典ID値 | rawGisRasterに格納する`N03_007`の整数値。 |
| 背景値 | `0`。区域コードが割り当てられていない地点を表し、辞書レコードを指さない。対象領域と背景になる条件は第1.3節を参照。 |
| GisWordBookコード | `x_district_id + 1`による1始まりの整数値。対応するGisWordBookの葉レコードを示す。 |
| マップコード | 原典ID値をcodemapで変換したGisWordBookコード。リリース利用時は同じ接頭辞のGisWordBookで解釈する。 |

## 3. 区画データ

### 3.1 論理データ要素

| データ要素 | 内容 |
| --- | --- |
| 区域地図 | 第1.3節の対象領域に属する行政区域を、GisWordBookの葉レコードに対応するコードで表す。 |
| GisWordBook | 都道府県、振興局、郡、市区町村、政令指定都市の行政区から成る固定5階層の名称辞書。 3種類の文字コード版はレコード順序、コードおよび論理内容が同一である。 |
| codemap | `N03_007`の原典ID値とGisWordBookコードの対応。製造時だけ使用し、リリースパッケージには含めない。 |

### 3.2 StringSet

GisWordBookの各レコードは次の5スロットの固定長パスを持つ。空スロットは詰めず、国名などの共通ノードは含めない。

| スロット | 意味 | 省略可否 |
| --- | --- | --- |
| 区域1 | 都道府県。`N03_001`の名称。 | 不可 |
| 区域2 | 振興局。`N03_002`の名称。 | 可。存在しない場合は空文字列。 |
| 区域3 | 郡。`N03_003`の名称。 | 可。存在しない場合は空文字列。 |
| 区域4 | 市区町村。`N03_004`の名称。 | 不可 |
| 区域5 | 政令指定都市の行政区。`N03_005`の名称。 | 可。存在しない場合は空文字列。 |

同じ表示名の区域が複数存在する場合も、GisWordBookコードで区別する。
